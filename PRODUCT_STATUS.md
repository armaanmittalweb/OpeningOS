# Product Status

## Current release

OpeningOS 0.5.1 is a deployable local-first product alpha with responsive UI polish and optional Appwrite cloud snapshots.

## Good for

- public demo deployment,
- real user feedback,
- personal opening preparation,
- serious local/private prep with backups,
- coaches assigning work through JSON coach packs,
- GitHub Pages hosting,
- PWA installation testing,
- cleaner desktop/tablet/mobile user testing,
- optional Appwrite cloud-backup testing for verified student deployments.

## Not yet a full SaaS

OpeningOS does not yet include:

- native OpeningOS-owned account login,
- production-grade multi-device conflict-safe sync beyond optional snapshot push/pull,
- real-time coach/student collaboration,
- billing,
- team permissions,
- server-side import queues,
- admin tools.

## Next production milestone

The next milestone is `0.6 SaaS foundation`:

- Supabase/Postgres or custom backend,
- auth,
- row-level permissions,
- production-grade multi-device conflict-safe sync beyond optional snapshot push/pull,
- IndexedDB offline cache,
- server-side migrations,
- team/coach sharing,
- error monitoring.
